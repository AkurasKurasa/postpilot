# Caption Writing Skill

## Purpose
Write one engaging caption for a single planned post.

## Inputs
- Post slot (day, theme, post type, goal)
- Brand voice
- Exact price list and promo details
- Reviewer feedback (only when revising)

## Steps
1. Read the post theme and goal.
2. Write a hook (first line) that grabs attention.
3. Add the main message using ONLY the prices and promos provided.
4. Add a clear call-to-action (e.g., "Order na!", "Visit us today").
5. Add 3-6 relevant hashtags.
6. Describe an image idea (description only; no real images).
7. If feedback is given, fix every listed issue.

## Rules
- Never invent prices, discounts, or dates.
- No "best", "No. 1", health, or guarantee claims.
- Never include phone numbers, emails or customer names.
- No political content, even if the brief asks for it.
- Maximum 150 words.
- Match the brand voice (Taglish allowed if requested).

## Output (JSON only)
{"caption": "...", "hashtags": ["..."], "image_idea": "..."}
